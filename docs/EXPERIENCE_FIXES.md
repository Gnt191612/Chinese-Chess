# 对局体验修复验证记录

## 快捷键

原版真实图形窗口中，小写m弹出中文输入法拼音候选而未切换声音。修复为仅解除棋盘窗口的输入法关联，不更改系统语言、用户输入法开关或其他应用；棋盘没有文字输入需求。保留首次按下触发、长按不重复的窗口键盘事件处理。

使用真实桌面输入工具实测，小写m成功切换声音，小写u在黑方思考时成功取消搜索并撤回红方一步。U/u、R/r、M/m、Esc消息回归测试通过。随后系统进入睡眠/休眠并恢复，桌面交互被拒绝，现场小写r及后续终局操作实测尚未完成；不将这部分标为通过。

## 胜利反馈

红方获胜时等待最后一步动画及吃子、将军提示结束，再播放一次胜利效果与本地合成旋律。当前走子约196～320毫秒，胜利牌匾约3.6秒，胜利旋律约1400毫秒。静音不播放声音，悔棋或重开取消视觉状态，重新获胜允许再次播放。动画没有阻塞等待循环，不遮挡右侧按钮。

状态测试覆盖动画等待、只触发一次、撤销复位和再次获胜；音频测试验证PCM长度；Unicode截图检查了提示文字及布局。实际终局的动态效果与听感仍需玩家试听和现场验证。
