# 第一版训练数据与教师选型

本文冻结第一版默认方案。实际下载时必须记录源码提交、文件校验值和获取日期；上游主分支后续发生变化时，不自动替换已经开始的训练版本。

## 1. 人类棋谱：CCPD

选择：`Yvonne761/Chinese-Chess-Practical-Dataset` 主分支在首次正式下载时的固定提交。

许可：CC BY 4.0。发布研究说明、模型卡和数据来源时保留作者、数据集名称、仓库链接、许可证链接及是否经过清洗转换的信息。

第一版只使用“大师对局”中的完整真人比赛构建 Human Prior。电脑对局、人机赛、残局题、杀法题和开局变化暂不混入人类选择分布；它们可在后续作为独立测试集或专项数据处理。

CCPD仓库按对局、棋手、赛事和开局等目录组织，但README没有承诺一个统一的逐局面表格字段。因此不把上游文件布局直接作为训练接口。下载后由转换器读取实际棋谱文件，统一输出本项目的JSONL格式。

### 统一局面字段

| 字段 | 类型 | 必填 | 含义 |
|---|---|---:|---|
| `id` | string | 是 | 稳定且全局唯一的局面ID |
| `game_id` | string | 是 | 原始整盘棋ID，用于防止数据泄漏 |
| `ply` | integer | 是 | 从0开始的半回合序号 |
| `fen` | string | 是 | 执行人类着法之前的中国象棋FEN |
| `human_move` | string | 是 | 与教师协议一致的坐标着法 |
| `result` | string | 是 | 红胜、黑胜、和棋或未知的规范值 |
| `split` | string | 是 | `train`、`validation`或`test` |
| `source_path` | string | 是 | 数据集内相对来源路径，不保存个人绝对路径 |
| `source_license` | string | 是 | 固定为 `CC-BY-4.0` |

训练集划分使用 `game_id`，同一盘棋的全部局面只能属于一个集合。重复收录的棋局先以规范化着法序列去重，再生成局面。

## 2. 主要价值教师：Pikafish

选择：官方 `Pikafish-2026-09-06` 发布版，Linux x86-64通用构建，搭配该发布包指定且校验匹配的NNUE权重。

职责：标注全部精选局面的候选着、局面分值和主变化，形成Value目标；不负责定义Human Prior。

协议：UCI，第一版 `MultiPV=3`。基准阶段使用单进程单线程、固定 `movetime`；正式预算由1万局面基准结果决定。

许可隔离：

- 引擎源码和程序为GPLv3。
- 官方Pikafish NNUE权重另有使用条款，包括未经许可不得商业使用。
- 教师引擎和NNUE权重由训练者从官方来源单独取得，不进入本项目Git仓库、Release或桌面软件包。
- 第一版只面向已经获准的非商业课程研究训练；目前暂不上传或占用学校服务器。
- 项目所有者已接受该边界：在未获得权利人明确许可或完成独立法律核对前，不声称蒸馏模型可用于商业用途。
- 最终模型发布前必须在模型卡中记录教师版本、权重名称及SHA-256，并重新审查训练产物的发布边界。

## 3. 分歧复核教师：ElephantEye

选择：`xqbase/eleeye`仓库中的ElephantEye 3.15；首次获取时固定具体提交并记录SHA-256。

许可：LGPL-2.1。教师只在离线任务中独立运行，不复制其源码进入本项目，也不与桌面程序链接或一起打包。

职责：只复核以下困难局面，不参与全部数据标注：

- 人类着法不在Pikafish前三候选；
- Pikafish前三候选分差很小；
- 不同搜索预算的评价方向不稳定；
- 局面接近胜负或和棋判断边界。

象眼采用UCCI 3.0，与现有UCI标注器协议不同。正式运行前必须完成独立UCCI适配器和小样本一致性测试。

## 4. 第一版暂不采用

### ElephantArt

它采用卷积神经网络和MCTS，能够提供有价值的异构意见，但第一版暂不采用，原因是还需要额外确认可复现权重、服务器GPU运行方式、UCCI适配和GPLv3附加条款。完成基础双教师流水线后再评估加入。

### 元萝、闪电及其他引擎

在找到可验证的官方仓库、固定版本、协议说明和明确许可证之前不加入训练。论坛转载包、网盘二进制或无法核对权重来源的版本不进入学校服务器。

## 5. 发布边界

计划公开的内容：本项目源码、转换与标注工具、配置模板、训练方法、统计结果，以及经许可审查后允许发布的最终轻量参数。

本项目自行编写的源码和文档采用MIT许可证。该MIT许可证不覆盖第三方数据、教师引擎、NNUE权重或尚未完成独立许可审查的蒸馏模型。

默认不公开或不随软件分发的内容：CCPD原始文件、皮卡鱼和象眼二进制、Pikafish NNUE权重、原始教师标签、学校任务日志和任何账号配置。
