# 轻量棋理评估首轮

本轮只修改运行时手工评估，不接入 NNUE、不训练模型、不添加强制开局应手，不改变 8.5 秒软限制和 9 秒硬限制。

## 特征与边界

- 兵卒：按当前所在路区分中路、三七路及边路，结合推进、过河、互保和到底调整。初始边兵、三七兵、中兵示例评分为 88、128、163；它们是内部启发式分，不是教师实测价值。五兵在对称开局中分为三类，左右同类等价，不为五个兵强行设置五种不同价值。
- 马：考虑蹩马腿、可到达格、居中和发展位置。
- 车炮：计算通路与伪合法活动空间，考虑车的推进、炮的位置及己兵贴身阻挡前路。
- 将帅：依双方剩余进攻子数量调整缺士象、离底线和偏离中路的风险，并考虑敌方车马炮的近将压力。

兵卒价值不是永久绑定出生列的身份属性。过河后的兵可以横移，评分会跟随它当前的作用变化。活动空间不是完整合法着数量，近将距离也不是已经形成杀势的证明；最终选择仍交给搜索。完整子力协调、复杂兵形与计划连续性尚未实现。
