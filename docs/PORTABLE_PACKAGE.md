# Windows成品包检查

成品包以最新圆形半透明徽章版为基础，目标为Windows x64。Release x64使用静态MSVC运行库，避免要求用户额外安装Visual C++运行库；EasyX仍作为编译依赖，不单独附库或安装包。

## 使用说明

解压到有写入权限的本地文件夹，双击“中国象棋.exe”；不要直接在ZIP内部运行。玩家执红先行，AI执黑；快捷键U/u悔棋、R/r重开、M/m声音、Esc退出。每次启动新局，可用“恢复上次／回到本次”切换棋局。

棋盘、棋子和声音由程序绘制或生成，不需要下载模型。包中不含个人经验库和棋局缓存；首次运行会建立自己的数据文件，之后移动程序时应同时保留这些文件。
