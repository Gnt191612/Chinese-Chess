# Windows安装版

成品包以最新圆形半透明徽章版为基础，目标为Windows x64。Release x64使用静态MSVC运行库，避免要求用户额外安装Visual C++运行库；EasyX仍作为编译依赖，不单独附库或安装包。

## 使用说明

成品仅提供 `中国象棋-Setup.exe`，双击后按中文向导安装。默认安装到当前用户的 `%LOCALAPPDATA%\Programs\ChineseChess`，无需管理员权限；可选择其他有写入权限的目录，不建议选系统Program Files目录。安装后从桌面或开始菜单启动，Windows应用设置中可卸载。玩家执红先行，AI执黑；快捷键U/u悔棋、R/r重开、M/m声音、Esc退出。每次启动新局，可用“恢复上次／回到本次”切换棋局。

棋盘、棋子和声音由程序绘制或生成，不需要下载模型。包中不含个人经验库和棋局缓存；首次运行在安装目录生成数据。升级时使用原安装目录，安装器只更新程序与说明，不覆盖经验和棋局；卸载也不递归清除这些运行数据。更换目录或电脑时应另行备份数据，安装器不自动迁移旧源码目录中的个人数据。

## 复现安装包

先用VS2022与EasyX构建Release x64（静态MSVC运行库），再执行：

```powershell
.\tools\BuildInstaller.ps1 -GameExe '.\build\成品构建\中国象棋.exe'
```

默认编译器为 `D:\Software\Inno Setup 7\ISCC.exe`，可通过 `-Compiler` 指定。输出 `build\installer\中国象棋-Setup.exe`；构建脚本拒绝覆盖旧包。Inno Setup是制作者的工具，玩家不需要安装。
