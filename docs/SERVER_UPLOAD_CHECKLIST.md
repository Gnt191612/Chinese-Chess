# 学校服务器上传前检查清单

## 先取得授权

- [x] 用户已确认获准使用学校服务器完成该项目的课程研究或科研计算；目前暂缓上传和使用。
- [ ] 确认允许运行第三方象棋引擎及保存相应权重。
- [ ] 确认数据集可以存放在学校共享存储中。
- [ ] 确认允许的队列、账户、并发任务数、单任务CPU数和存储配额。

## 只上传必要内容

- `tools/training/`
- `training/config/` 中由示例复制得到的本地配置
- `training/slurm/`
- 已获许可并完成清洗的局面分片
- 用户自行准备且获准使用的教师引擎与权重

不要上传 `.vs/`、Windows构建产物、个人经验库、Git凭据、SSH私钥或与训练无关的整个桌面工程。

## 上传后先做小任务

1. 在登录节点只运行 `python3 tools/training/preflight.py --repo . --config training/config/local.json`；不要在登录节点执行引擎计算。
2. 提交一个1小时以内、1万局面的基准任务。
3. 检查吞吐量、失败率、内存峰值和输出完整性。
4. 用实测结果计算正式机时，再分批提交。
5. 每个任务独立写入分片结果，已存在且验证通过的结果不重复计算。

## 下载结果前

- [ ] 合并器确认每个输入ID恰好对应一个有效结果或一条明确错误记录。
- [ ] 保存任务配置、引擎版本、权重校验值、Slurm任务号和日志摘要。
- [ ] 不下载来源不明或许可不清楚的共享文件。
