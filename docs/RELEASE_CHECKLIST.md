## 本地源码包准备

首次发布的仓库名称、介绍、范围建议和所有者确认事项见 [GitHub发布准备](GITHUB_PUBLICATION.md)。最新源码包包含 `.github/` 模板；当前仅准备源码候选，不附二进制或模型。

使用PowerShell 7在项目目录执行：

```powershell
.\tools\ExportSource.ps1 -OutputDirectory 'D:\准备上传\中国象棋-v0.1.0-rc.1-source'
```

目标目录与同名ZIP必须不存在，脚本拒绝覆盖已有文件。脚本导出Git未忽略的源码、测试、文档和训练配置，包含尚未提交的新增源码；再次按忽略规则排除个人缓存、经验库、教师程序、模型、原始数据和编译产物，并生成SHA-256清单。源码包不附带EasyX安装包或编译后的可执行文件；接收者按README另行安装构建依赖。

本地Git仍需人工审阅、提交和设置远端后才能推送。本次准备不执行 `git add`、提交、推送、仓库创建、服务器上传或GitHub发布。最终发布前仍须确认本人有权公开现有源码，并核对第三方边界；“已生成源码包”不等于完成法律或商业可用审查。
